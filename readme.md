# Workspace — Giuseppe Giovanni Farhat D'Elia

Espacio centralizado de trabajo, laboratorio de pruebas y repositorio de desarrollo personal. Este repositorio alberga proyectos en curso, utilidades de automatización, arquitecturas de software y recursos técnicos desarrollados durante mi formación en Desarrollo de Aplicaciones Web (DAW).

---

## Perfil Técnico

Desarrollador orientado al backend y arquitectura web, enfocado en el diseño de soluciones eficientes, gestión de bases de datos relacionales y optimización de flujos de trabajo.

* **Backend:** Java, PHP, Python
* **Frontend:** JavaScript (ES6+), HTML5, CSS3
* **Bases de Datos:** PostgreSQL, MySQL
* **Entornos y Herramientas:** Git, Linux, Windows, VS Code, XAMPP

* **Proyectos & Módulos:** Implementaciones completas, pruebas de concepto y lógica de negocio.
