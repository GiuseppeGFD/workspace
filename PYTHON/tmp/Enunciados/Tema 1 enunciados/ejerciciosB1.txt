Ejercicio 3. Media de cuatro calificaciones
Solicita cuatro calificaciones, todas con el mismo peso, y calcula la nota media.

Muestra la nota media con 2 decimales. Para ello, utiliza una f-string: f"{numero:.2f}".

La letra f al inicio indica a Python que vas a introducir una variable dentro del texto utilizando llaves {}.

Dentro de las llaves, los dos puntos : seguidos de .2f indican que se deben mostrar exactamente dos números después del punto decimal.

El 2 indica que quieres exactamente dos decimales.
La f viene de float, que es el tipo utilizado para representar números con decimales.
