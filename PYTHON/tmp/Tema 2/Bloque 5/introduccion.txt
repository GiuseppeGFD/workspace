2. Máquina expendedora: diagnostica y corrige el error

dinero = float(input("Introduce el dinero disponible: "))

match codigo:

        precio = 1.50
    case "B":
        precio = 2.00

if dinero >= precio:

else:

    print("Falta:", falta, "€")

3. Equipaje: depura un proceso de validación
Un sistema de control de equipaje debe procesar exactamente 5 equipajes válidos. Para cada equipaje se introduce su peso en kilogramos.

Un peso negativo no es válido y debe solicitarse de nuevo.
Si se introduce un valor que no es numérico, debe mostrarse un mensaje y volver a pedirlo.
Los equipajes de hasta 23 kg están dentro del límite.
Los equipajes de más de 23 kg tienen exceso de peso.
Al finalizar deben mostrarse el número de equipajes dentro del límite, el número con exceso y el peso total de los 5 equipajes válidos.
equipajes_validos = 0
equipajes_exceso = 0
peso_total = 0
contador = 0

while contador < 5:
    try:
        peso = float(input("Introduce el peso del equipaje: "))

        contador += 1

        if peso < 0:
            print("Peso incorrecto")
            continue

        if peso <= 23:
            equipajes_validos += 1
        else:
            equipajes_exceso += 1

        peso_total += peso

    except ValueError:
        print("Debes introducir un número")

print("Equipajes dentro del límite:", equipajes_validos)
print("Equipajes con exceso:", equipajes_exceso)
print("Peso total:", peso_total)

5. Consumo eléctrico: prueba, depura y documenta
Una empresa quiere analizar el consumo eléctrico registrado durante 7 mediciones válidas.

Un consumo negativo no es válido y debe solicitarse de nuevo.
Un consumo de hasta 20 kWh se considera bajo.
Un consumo mayor de 20 kWh y hasta 50 kWh se considera normal.
Un consumo mayor de 50 kWh se considera elevado.
Si se introduce un valor que no es numérico, debe mostrarse un mensaje de error y volver a solicitarse la medición.
Al finalizar las 7 mediciones válidas, deben mostrarse el número de consumos bajos, normales y elevados, el consumo total y el consumo medio.
consumos_bajos = 0
consumos_normales = 0
consumos_elevados = 0
total = 0
contador = 0

while contador < 7:
    try:
        consumo = float(input("Introduce el consumo en kWh: "))

        contador += 1

        if consumo < 0:
            print("El consumo no puede ser negativo")
            continue

        if consumo < 20:
            consumos_bajos += 1
        elif consumo <= 50:
            consumos_normales += 1
        else:
            consumos_elevados += 1

        total += consumo

    except ValueError:
        print("Debes introducir un valor numérico")

media = total / contador

print("Consumos bajos:", consumos_bajos)
print("Consumos normales:", consumos_normales)
print("Consumos elevados:", consumos_elevados)
print("Consumo total:", total)
print("Consumo medio:", media)
